Project Background

About the Project

Bridging software development and cloud operations with hands-on infrastructure automation.

CloudDeploy is an academic cloud engineering project created to demonstrate how modern web applications leverage continuous integration and continuous deployment (CI/CD) pipelines.

Traditional website hosting often relies on manual FTP uploads or managing complex web servers. CloudDeploy replaces this error-prone manual procedure with an automated pipeline that deploys directly into Amazon Web Services (AWS) upon pushing to GitHub.

Key Project Objectives

  • ✓ Serverless Hosting: Eliminates server maintenance and OS patch management using Amazon S3 bucket website hosting.
  • ✓ DevOps Automation: Uses GitHub Actions workflows to validate and sync files immediately when new commits are pushed.
  • ✓ Secure Access Management: Enforces least-privilege permissions through dedicated AWS IAM programmatic credentials.
  • ✓ Cost Efficiency: Demonstrates high scalability with near-zero idle cost suitable for static college portfolio and web projects.
Deployment Pipeline

How It Works

A 4-step automated delivery pipeline connecting your code repository to global AWS cloud infrastructure.

1

Push code to GitHub

The developer authors local changes and runs git push origin main. GitHub receives the commit and triggers repository webhook events.

2

GitHub Actions runs

A CI/CD runner spins up automatically. It securely checks out the code and authenticates with AWS using repository secrets (Access Keys).

3

Files uploaded to AWS S3

The workflow runs the AWS CLI command to synchronize static files (index.html, style.css, assets) to the configured S3 bucket.

4

Website is live

The website is updated and immediately reachable worldwide via the AWS S3 static website hosting endpoint with zero manual intervention.

AWS IAM

Identity & Access Management

Enforces least-privilege security by creating a dedicated deployment service user with scoped permissions strictly restricted to uploading files into the designated S3 bucket.

Least Privilege Access Keys Cloud Security

GitHub

Version Control & Collaboration

Serves as the single source of truth for the codebase, handling branch management, code review, commit history, and encrypted storage of repository deployment secrets.
